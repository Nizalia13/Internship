\subsection{Score Transformation}
- General formulation: for each class $y \in \mathcal{Y}$, define a transformation $\phi_y$:$[0,1]^K \to [0,1]^K$ that maps the raw score vector to an conformal score vector such that a true infector of class $y$ is near the origin\\
- Property we require: $phi_y(\mathbf{s})$ is small when $\mathbf{s}$ is consistent with label $y$, large otherwise\\
- we make a single unified envelope coherent across all classes
